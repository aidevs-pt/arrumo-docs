Claude Code redacta guiones, planifica recursos, diseña animaciones y traduce subtítulos con tu plan de Claude. Para generar imágenes necesitas una clave de [OpenAI](../openai/images.mdx) o [Gemini](../gemini/images.mdx).

## Configúralo

Necesitas un plan Claude Pro, Max, Team o Enterprise, o una cuenta de Anthropic Console. Las cuentas gratuitas de Claude no pueden usar Claude Code. ¿Es tu primer agente? [Conecta un agente](../../user/agents.mdx) explica qué hacen.

<Steps>
<Step>

### Instala Claude Code

Abre un terminal, pega el comando para tu ordenador y pulsa Intro. No necesita permisos de administrador y mantiene Claude Code actualizado por sí solo.

<Tabs groupId="os" persist items={["Windows", "macOS", "Linux"]}>
<Tab value="Windows">

Abre el menú **Inicio**, escribe `PowerShell` y abre **Windows PowerShell**. Después pega:

```powershell
irm https://claude.ai/install.ps1 | iex
```

![Instalar Claude Code en PowerShell](/tools/arrumo/static/media/agents/claude-install-windows.webp)

Claude Code necesita Windows 10 de 64 bits (versión 1809) o posterior. Git para Windows es opcional.

</Tab>
<Tab value="macOS">

Abre **Terminal** desde **Aplicaciones › Utilidades**, o búscalo con Spotlight. Después pega:

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

![Instalar Claude Code en el Terminal de macOS](/tools/arrumo/static/media/agents/claude-install-macos.webp)

</Tab>
<Tab value="Linux">

Abre tu terminal, por ejemplo con **Ctrl+Alt+T** en Ubuntu. Después pega:

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

![Instalar Claude Code en un terminal de Linux](/tools/arrumo/static/media/agents/claude-install-linux.webp)

No añadas `sudo`: Claude Code se instala en tu propia carpeta personal.

</Tab>
</Tabs>

**Claude Code successfully installed!** y la línea **Location** indican que ha funcionado. Si el instalador muestra **Setup notes** sobre tu `PATH`, solo afecta a escribir `claude` en un terminal; Arrumo puede usarlo igualmente (consulta [Si Arrumo no lo encuentra](#si-arrumo-no-lo-encuentra)). La [guía de instalación](https://code.claude.com/docs/en/setup) de Anthropic recoge otras formas de instalarlo.

</Step>
<Step>

### Inicia sesión

En el mismo terminal, ejecuta:

```sh
claude auth login
```

Tu navegador abre la página de inicio de sesión de Anthropic. Inicia sesión con tu cuenta de Claude y aprueba el acceso; después puedes cerrar la pestaña. Para confirmarlo, ejecuta `claude auth status`: muestra `"loggedIn": true`.

Inicias sesión en la propia página de Anthropic. Arrumo nunca ve tu contraseña ni los tokens de tu cuenta.

</Step>
<Step>

### Elígelo en Arrumo

Abre Arrumo. En el primer paso de la configuración, Claude Code muestra **CLI del agente encontrada**; elige **Usar Claude Code**. Si Arrumo ya estaba abierto mientras lo instalabas, elige **Volver a comprobar** (la flecha circular).

![Claude Code y Codex encontrados durante la configuración](/tools/arrumo/static/media/agents/agent-found.webp)

¿Ya lo configuraste? Elige Claude Code en **Ajustes › Agente** y guarda.

</Step>
<Step>

### Comprueba el inicio de sesión

En **Ajustes › Agente**, elige **Comprobar inicio de sesión**. **La CLI indica que hay una sesión local.** significa que todo está listo. La comprobación no inicia ninguna edición ni usa tu plan.

![Ajustes › Agente con Claude Code encontrado y con la sesión iniciada](/tools/arrumo/static/media/agents/settings-claude-code.webp)

</Step>
</Steps>

### Si Arrumo no lo encuentra

Arrumo busca `claude` en tus carpetas de programas habituales y en las que añade tu shell de inicio de sesión, incluso cuando abres Arrumo desde el Dock, el Finder o un lanzador del escritorio.

- ¿Lo instalaste con Arrumo abierto? Elige **Volver a comprobar**.
- ¿Sigue diciendo **No se encontró la CLI del agente**? Elige **Elegir el programa…** (el botón de la carpeta durante la configuración) y selecciona el archivo que el instalador indicó en **Location**:
  - Windows: `C:\Users\<tú>\.local\bin\claude.exe`. La carpeta `.local` puede estar oculta; escribe la ruta en el cuadro de diálogo.
  - macOS y Linux: `~/.local/bin/claude`. Pulsa **Cmd+Mayús+.** en macOS, o **Ctrl+H** en Linux, para ver las carpetas ocultas.
- **La CLI no confirmó el inicio de sesión.** significa que Claude Code no tiene la sesión iniciada: vuelve a ejecutar `claude auth login` y elige **Comprobar inicio de sesión**.

## Comprueba la conexión

Desde la CLI del editor, indica la ruta de una base de datos local y el identificador de este complemento.

```sh
arrumo-workspaces ./workspaces.sqlite agent-login-status claude-code
```

El estado confirmed indica que la CLI aceptó la comprobación. Si Arrumo devuelve unavailable, comprueba que la CLI esté instalada o elige su archivo de programa en Ajustes. Si devuelve unconfirmed, inicia sesión según la guía oficial y vuelve a comprobarlo. Un tiempo de espera agotado o un error indica que la comprobación no pudo completarse.

## Escribir archivos y ejecutar comandos

**Escribir archivos y ejecutar comandos**, en Ajustes › Agente, está activado por defecto. Mientras trabaja en un vídeo, Claude Code acepta las ediciones (`--permission-mode acceptEdits`) y puede usar Read, Write, Edit, Glob, Grep y Bash, además de WebSearch y WebFetch cuando **Búsqueda web** está activada. Se aplica tu propia configuración de Claude Code: sus hooks, servidores MCP y complementos. Trabaja en una carpeta que Arrumo crea para ese vídeo y borra cuando el vídeo termina, falla o se cancela.

Si lo desactivas, Claude Code se ejecuta en modo restringido (`--restricted`), con los hooks desactivados y sin herramientas de archivos ni de terminal, y solo lee lo que Arrumo le envía. **Usar mis complementos instalados** decide entonces si se cargan tus complementos y servidores MCP.

## Traduce los subtítulos

Consulta [la traducción de subtítulos](https://github.com/aidevs-pt/arrumo-plugin-claude-code/blob/main/README.md#translate-subtitles) para usar este complemento como traductor de Auto-Dubbing. El traductor envía a Claude Code el texto de los subtítulos seleccionados y el idioma de destino. El proceso conserva las marcas de tiempo originales.

## Preguntas de seguimiento

Cuando Claude Code pide a Arrumo material del espacio de trabajo, como el guion de un vídeo anterior, Arrumo responde en la misma sesión de Claude Code solo con ese material, así el encargo no se envía ni se paga dos veces. Estas sesiones quedan en el historial de Claude Code (`claude --resume`); las ejecuciones puntuales no guardan ninguna.
