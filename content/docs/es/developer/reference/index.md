La CLI, MCP y A2A llaman a la misma API de la aplicación, así que cada página muestra los tres juntos. Ejecuta los comandos de la CLI como `arrumo-workspaces <ruta-de-la-base-de-datos> <comando>`, o `cargo run --locked -- <ruta-de-la-base-de-datos> <comando>` desde el repositorio del editor.

- [Compila y ejecuta el editor](build.md): desarrollo de escritorio, complementos incluidos, traducciones y enlaces profundos.
- [Espacios de trabajo, perfiles y recursos](workspaces.md): copias de seguridad, perfiles, formatos de salida, recursos, contexto y marca.
- [Borradores, ejecuciones y revisión](runs.md): cola, workers, el agente de edición, resultados de cada etapa y vídeos completados.
- [Renderizado, subtítulos y entrega](rendering.md): vistas previas, renderizado final, comprobación de la entrega, subtítulos y exportación.
- [Biblioteca de animaciones y transiciones](motion.md): elementos de la biblioteca, animaciones diseñadas por el agente y renderizadores de movimiento.
- [Complementos y proveedores](plugins.md): instalación, ajustes, credenciales, orden de proveedores, entorno de ejecución y acciones.
- [MCP y A2A](transports.md): cómo conectar un cliente a cada transporte.
