La CLI, MCP y A2A llaman a la misma API de la aplicación, así que cada página muestra los tres juntos. Ejecuta los comandos de la CLI como `arrumo-workspaces <ruta-de-la-base-de-datos> <comando>`, o `cargo run --locked -- <ruta-de-la-base-de-datos> <comando>` desde el repositorio del editor.
