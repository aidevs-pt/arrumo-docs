---

title: "Plugins oficiais"
description: "Plugins criados e mantidos pela DEVS AI."
---

Estes plugins vêm do [registo oficial](https://github.com/aidevs-pt/arrumo-plugin-registry). O Arrumo instala-os no primeiro arranque e ativa-os; os plugins que importares começam desativados. Ativa ou desativa cada um com o interruptor na respetiva página em **Definições › Plugins**. Um plugin desativado mantém as definições, mas o Arrumo não o usa.

| Plugin                                       | O que faz                                                              |
| -------------------------------------------- | ---------------------------------------------------------------------- |
| [Auto-Dubbing](auto-dubbing/dub-a-video.md)  | Dobra vídeos terminados para outras línguas.                           |
| [Claude Code](claude-code/setup.md)          | Agente de edição com a tua sessão local do Claude Code.                |
| [Codex](codex/setup.md)                      | Agente de edição com a tua sessão local do Codex; também cria imagens. |
| [ElevenLabs](elevenlabs/transcription.md)    | Transcrição e narração.                                                |
| [Gemini](gemini/images.md)                   | Miniaturas e imagens.                                                  |
| [Higgsfield](higgsfield/video-and-images.md) | Clipes de vídeo e imagens gerados.                                     |
| [OpenAI](openai/transcription.md)            | Transcrição e imagens.                                                 |
