O agente do Arrumo e cada serviço que usa para criar media vêm de plugins. Os oficiais vêm do [registo oficial](https://github.com/aidevs-pt/arrumo-plugin-registry): o Arrumo instala-os no primeiro arranque, ativa-os e atualiza-os dentro da própria app com versões verificadas. Os plugins que importas começam desativados.

Ativa ou desativa cada plugin com o interruptor na sua página em **Definições › Plugins**. Um plugin desativado mantém as definições, mas o Arrumo não o usa. As chaves vão em **Definições › Serviços e chaves**, para todos os espaços de trabalho ou para um: a chave de um espaço tem prioridade sobre a da app. Ficam guardadas cifradas no cofre do teu sistema, e os agentes usam-nas através do Arrumo sem nunca as conseguirem ler.

## Quem faz o quê

Quando vários plugins podem fazer o mesmo trabalho, o Arrumo experimenta-os pela ordem de **Definições › Serviços e chaves › Que plugin faz o quê, por ordem**, e passa ao seguinte se um falhar ou ficar sem saldo. Um espaço de trabalho pode seguir a ordem da app ou definir a sua, e cada vídeo mantém a ordem com que começou.

| Capacidade                               | Plugins                               | Precisa de                                    |
| ---------------------------------------- | ------------------------------------- | --------------------------------------------- |
| Agente de edição                         | Claude Code, Codex                    | O agente instalado e com sessão iniciada      |
| Transcrição                              | ElevenLabs, OpenAI                    | Uma chave de API                              |
| Texto para voz                           | ElevenLabs                            | Uma chave de API                              |
| Música, efeitos sonoros                  | ElevenLabs                            | Uma chave de API                              |
| Mudança de voz, isolamento de voz, dobragem | ElevenLabs                         | Uma chave de API                              |
| Geração de imagens                       | Codex, OpenAI, Gemini, Higgsfield     | Codex: o teu plano do ChatGPT; os outros: uma chave |
| Geração de vídeo                         | Higgsfield                            | Uma chave de API                              |
| Tradução de legendas                     | Claude Code, Codex                    | O agente com sessão iniciada                  |

## Privacidade

Um plugin fornecedor envia só o que o trabalho precisa, como o áudio de um clipe para transcrever ou uma descrição e imagens de referência para uma imagem, e só para a API desse fornecedor. O Arrumo faz o pedido; o agente nunca vê a chave. As tuas gravações ficam no teu computador, a não ser que um plugin que ativaste carregue uma parte para um trabalho que tu ou o agente pediram.

## Cria o teu

Os plugins são pacotes descritos por um manifesto. Os fornecedores de agentes, os fornecedores de media, as ações e os modelos de animação são escritos com o [SDK de plugins](../developer/sdk/index.mdx); começa por [Compila e executa o teu primeiro plugin](../developer/first-plugin.mdx).
