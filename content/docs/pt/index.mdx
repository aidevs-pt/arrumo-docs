O Arrumo AI Video Editor é um editor de vídeo para computador, gratuito e de código aberto, em que um agente de IA escreve o guião, corta as tuas gravações, cria animações e renderiza cada formato, e tu revês cada passo.

[![Ver «Conhece o Arrumo» no YouTube, um vídeo feito inteiramente no Arrumo](/tools/arrumo/static/media/videos/01-meet-arrumo.webp)](https://youtu.be/v2KcwE8xuso)

_Todos os vídeos desta documentação foram feitos inteiramente no Arrumo: o agente escreveu-os, desenhou-os, narrou-os e montou-os, e uma pessoa aprovou cada passo._

## Para agentes de IA

Cada página também está disponível em Markdown, para que um agente possa ler esta documentação sem a extrair da web:

| O quê                          | Onde                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- |
| Uma página                     | O endereço da página mais `.md`, como [`/pt/tools/arrumo/docs/user/install.md`](https://www.aidevs.pt/pt/tools/arrumo/docs/user/install.md) |
| A página inicial da documentação | [`/pt/tools/arrumo/docs/index.md`](https://www.aidevs.pt/pt/tools/arrumo/docs/index.md)          |
| Um índice de todas as páginas  | [`/pt/tools/arrumo/llms.txt`](https://www.aidevs.pt/pt/tools/arrumo/llms.txt)                        |
| Todas as páginas num ficheiro  | [`/pt/tools/arrumo/llms-full.txt`](https://www.aidevs.pt/pt/tools/arrumo/llms-full.txt)              |
| Uma secção num ficheiro        | O endereço da secção mais `/llms-full.txt`, como `/pt/tools/arrumo/docs/plugins/llms-full.txt`       |

O inglês não tem prefixo e o espanhol está em `/es`, como `/tools/arrumo/llms.txt` e `/es/tools/arrumo/llms.txt`. Os botões **Copiar Markdown** e **Abrir** de cada página fazem o mesmo para quem cola uma página num chat.

Para que um agente controle o Arrumo, em vez de ler sobre ele, vê [Liga-te ao Arrumo](developer/connect.mdx) e a [skill para agentes](developer/agent-skill.mdx).
