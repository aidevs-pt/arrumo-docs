---

title: "Official plugins"
description: "Plugins made and maintained by DEVS AI."
---

These plugins come from the [official registry](https://github.com/aidevs-pt/arrumo-plugin-registry). Arrumo installs these on first launch and turns them on; plugins you import start off. Turn each one on or off with the switch on its page in **Settings › Plugins**. A plugin that is off keeps its settings, but Arrumo doesn't use it.

| Plugin                                       | What it does                                                     |
| -------------------------------------------- | ---------------------------------------------------------------- |
| [Auto-Dubbing](auto-dubbing/dub-a-video.md)  | Dubs finished videos into other languages.                       |
| [Claude Code](claude-code/setup.md)          | Editing agent using your local Claude Code sign-in.              |
| [Codex](codex/setup.md)                      | Editing agent using your local Codex sign-in; also makes images. |
| [ElevenLabs](elevenlabs/transcription.md)    | Transcription and narration.                                     |
| [Gemini](gemini/images.md)                   | Thumbnails and images.                                           |
| [Higgsfield](higgsfield/video-and-images.md) | Generated video clips and images.                                |
| [OpenAI](openai/transcription.md)            | Transcription and images.                                        |
