Claude Code drafts scripts, plans assets, designs animations and translates subtitles, using your Claude plan. Image generation needs an [OpenAI](../openai/images.mdx) or [Gemini](../gemini/images.mdx) key.

## Set it up

You need a Claude Pro, Max, Team or Enterprise plan, or an Anthropic Console account. Free Claude accounts can't use Claude Code. New to agents? [Connect an agent](../../user/agents.mdx) explains what they do.

<Steps>
<Step>

### Install Claude Code

Open a terminal, paste the command for your computer and press Enter. It needs no administrator rights and keeps Claude Code up to date on its own.

<Tabs groupId="os" persist items={["Windows", "macOS", "Linux"]}>
<Tab value="Windows">

Open the **Start** menu, type `PowerShell` and open **Windows PowerShell**. Then paste:

```powershell
irm https://claude.ai/install.ps1 | iex
```

![Installing Claude Code in PowerShell](/tools/arrumo/static/media/agents/claude-install-windows.webp)

Claude Code needs 64-bit Windows 10 (version 1809) or later. Git for Windows is optional.

</Tab>
<Tab value="macOS">

Open **Terminal** from **Applications › Utilities**, or search for it with Spotlight. Then paste:

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

![Installing Claude Code in the macOS Terminal](/tools/arrumo/static/media/agents/claude-install-macos.webp)

</Tab>
<Tab value="Linux">

Open your terminal, for example with **Ctrl+Alt+T** on Ubuntu. Then paste:

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

![Installing Claude Code in a Linux terminal](/tools/arrumo/static/media/agents/claude-install-linux.webp)

Don't add `sudo`: Claude Code installs into your own home folder.

</Tab>
</Tabs>

**Claude Code successfully installed!** and the **Location** line tell you it worked. If the installer shows **Setup notes** about your `PATH`, that only affects typing `claude` in a terminal; Arrumo can still use it (see [If Arrumo doesn't find it](#if-arrumo-doesnt-find-it)). Anthropic's [setup guide](https://code.claude.com/docs/en/setup) lists other ways to install it.

</Step>
<Step>

### Sign in

In the same terminal, run:

```sh
claude auth login
```

Your browser opens Anthropic's sign-in page. Sign in with your Claude account and approve the access; then you can close the browser tab. To confirm, run `claude auth status`: it shows `"loggedIn": true`.

You sign in on Anthropic's own page. Arrumo never sees your password or account tokens.

</Step>
<Step>

### Choose it in Arrumo

Open Arrumo. In the first setup step, Claude Code shows **Agent CLI found**; choose **Use Claude Code**. If Arrumo was already open while you installed it, choose **Check again**.

![Claude Code and Codex found during setup](/tools/arrumo/static/media/agents/agent-found.webp)

Already set up? Choose Claude Code in **Settings › Agent** and save.

</Step>
<Step>

### Check the sign-in

In **Settings › Agent**, choose **Check sign-in**. **The CLI reports a local sign-in.** means you're ready. The check doesn't start an edit or use your plan.

![Settings › Agent with Claude Code found and signed in](/tools/arrumo/static/media/agents/settings-claude-code.webp)

</Step>
</Steps>

### If Arrumo doesn't find it

Arrumo looks for `claude` in your usual program folders and the ones your login shell adds, even when you open Arrumo from the Dock, Finder or a desktop launcher.

- Installed it while Arrumo was open? Choose **Check again**.
- Still **Agent CLI not found**? Choose **Choose the program…** (the folder button during setup) and pick the file the installer listed under **Location**:
  - Windows: `C:\Users\<you>\.local\bin\claude.exe`. The `.local` folder may be hidden; type the path into the file dialog.
  - macOS and Linux: `~/.local/bin/claude`. Press **Cmd+Shift+.** on macOS, or **Ctrl+H** on Linux, to show hidden folders.
- **The CLI did not confirm a sign-in** means Claude Code isn't signed in: run `claude auth login` again, then choose **Check sign-in**.

## Check the connection

From the editor CLI, pass a local database path and this plugin ID.

```sh
arrumo-workspaces ./workspaces.sqlite agent-login-status claude-code
```

A confirmed status means the CLI accepted the sign-in probe. If Arrumo reports unavailable, check that the CLI is installed, or choose its program file in Settings. If the login is unconfirmed, sign in using the official guide and check again. A timeout or failure means the probe could not finish successfully.

## Write files and run commands

**Write files and run commands**, in Settings › Agent, is on by default. While working on a video, Claude Code then runs with edits accepted (`--permission-mode acceptEdits`) and may use Read, Write, Edit, Glob, Grep and Bash, plus WebSearch and WebFetch when **Web search** is on. Your own Claude Code setup applies: its hooks, MCP servers and plugins. It works in a folder Arrumo makes for that video and deletes once the video is finished, fails or is cancelled.

Turn it off and Claude Code runs restricted (`--restricted`), with hooks turned off and file and shell tools refused, and only reads what Arrumo sends. **Use my installed plugins** then decides whether your own plugins and MCP servers load.

## Translate subtitle cues

See [Translate subtitles](https://github.com/aidevs-pt/arrumo-plugin-claude-code/blob/main/README.md#translate-subtitles) to use this plugin as an Auto-Dubbing translator. The translator sends the selected cue text and target language to Claude Code. The workflow keeps the original cue timings.

## Follow-up questions

When Claude Code asks Arrumo for workspace material, such as an earlier video's script, Arrumo answers in the same Claude Code session with only that material, so the brief is not sent and paid for twice. These sessions are kept in Claude Code's own history (`claude --resume`); one-off runs keep none.
