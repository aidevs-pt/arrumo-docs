OpenAI makes the thumbnails for each format and any image you ask for in **Assets › Generate**. When a format asks for thumbnails, the agent writes one image prompt per thumbnail, using the format's **Thumbnail reference images** and your brand, and Arrumo asks the image providers in the video's order. Generated thumbnails are saved as workspace assets and wait for your review with the titles and descriptions.

## Set it up

Create a key on the [OpenAI API keys page](https://platform.openai.com/api-keys) and paste it under OpenAI in **Settings › Services and keys**. A workspace key takes precedence over the app's; agents use it through Arrumo but never see it. Under **Which plugin does what, in order**, move OpenAI up for **Image generation** to prefer it. Providers without a key are skipped.

## Sizes and references

| Aspect ratio | Size        |
| ------------ | ----------- |
| 16:9         | 1536 × 1024 |
| 9:16         | 1024 × 1536 |
| 1:1          | 1024 × 1024 |

With reference images, such as earlier thumbnails or a character, OpenAI edits from up to four of them. Each image can be up to 20 MB.
