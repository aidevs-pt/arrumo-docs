Arrumo AI Video Editor is a free, open-source desktop video editor where an AI agent drafts the script, cuts your footage, makes animations and renders every format, and you review each step.

[![Watch “Meet Arrumo” on YouTube, a video made entirely in Arrumo](https://www.aidevs.pt/tools/arrumo/static/media/videos/01-meet-arrumo.webp)](https://youtu.be/v2KcwE8xuso)

_Every video in these docs was made entirely in Arrumo: the agent wrote, designed, voiced and cut it, and a person approved each step._

## For AI agents

Every page is also available as Markdown, so an agent can read these docs without scraping them:

| What                      | Where                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------- |
| One page                  | The page's address plus `.md`, such as [`/tools/arrumo/docs/user/install.md`](https://www.aidevs.pt/tools/arrumo/docs/user/install.md) |
| The docs home             | [`/tools/arrumo/docs/index.md`](https://www.aidevs.pt/tools/arrumo/docs/index.md)                                      |
| An index of every page    | [`/tools/arrumo/llms.txt`](https://www.aidevs.pt/tools/arrumo/llms.txt)                                                |
| Every page in one file    | [`/tools/arrumo/llms-full.txt`](https://www.aidevs.pt/tools/arrumo/llms-full.txt)                                      |
| One section in one file   | The section's address plus `/llms-full.txt`, such as `/tools/arrumo/docs/plugins/llms-full.txt`   |

Spanish and Portuguese live under `/es` and `/pt`, such as `/es/tools/arrumo/llms.txt`. Each page's **Copy Markdown** and **Open** buttons do the same for people pasting a page into a chat.

To let an agent operate Arrumo itself, rather than read about it, see [Connect to Arrumo](developer/connect.mdx) and the [agent skill](developer/agent-skill.mdx).
