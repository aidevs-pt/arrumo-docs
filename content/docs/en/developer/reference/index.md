The CLI, MCP and A2A call the same application API, so each page lists the three side by side. Run CLI commands as `arrumo-workspaces <database-path> <command>`, or `cargo run --locked -- <database-path> <command>` from the editor repository.

- [Build and run the editor](build.md): desktop development, bundled plugins, translations and deep links.
- [Workspaces, profiles and assets](workspaces.md): backups, profiles, output formats, assets, context and brand.
- [Drafts, runs and review](runs.md): queuing, workers, the editing agent, stage results and completed videos.
- [Rendering, subtitles and delivery](rendering.md): previews, final render, delivery checks, subtitles and export.
- [Animation and transition library](motion.md): library items, agent-designed animations and motion renderers.
- [Plugins and providers](plugins.md): installation, settings, credentials, provider order, runtime and actions.
- [MCP and A2A](transports.md): connecting a client to each transport.
